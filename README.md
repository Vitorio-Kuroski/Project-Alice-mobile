# Project Alice mobile

Compilação para Android do [Project Alice](https://github.com/schombert/Project-Alice), um motor de código aberto para jogar Victoria 2.

O código C++ do jogo roda nativamente no celular (ARM64, OpenGL ES 3.2), com controles por toque. É preciso ter os arquivos originais do Victoria 2 com as expansões.

**Como instalar, jogar, compilar e como o port funciona: veja [android/README.md](android/README.md).**

> O app compila e gera um APK, mas ainda não foi testado num aparelho real.
